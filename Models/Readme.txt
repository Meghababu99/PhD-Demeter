


For all the scripts the Grid based Data is used (other than in the Trails folder) 



ADTK - All has Anomaly detection tool kit applied for anomaly detection for a given gridcell data(its a practice file)

ADTK-Kmean - K mean clustering applied and analysed the data(trail and error)


LSTM-AE_W2-DN-Trainfit-1.pth  - The best-fit model, trained for  data 2005/jan 1 to 2008/June with the same model architecture of LSTM-AE-2_DnOrbits_Final.ipynb for 2 half orbits together


Folder Trail - has all the model trials in the earlier part of the research


LSTM-AE-2_DnOrbits_Final - Final version with all necessary parts of Aggregate and Fb specific analysis


LSTM-AE-2_DnOrbits-Full_analysis - has the extended version of analysis, looking for Max error points in sequences, ..


LSTM-AE-Half_DnOrbit - Has the same analysis and model for just 1/2 of a day orbit as the input sequence


LSTM-Classifier_Final - Classifier. Here i have used the correct dataset which is background corrected by 3 years of data[2005,2007].IN this I have done the labeling right while defining the pytorch dataset 


LSTM-Classifier-Optune - it's an old version, but kept as an example of how to apply Optuna for hyper parameter
